Punch Analytics MCP - federated thin-client shim. Routes the configured Punch backends (the pa_v2 SAP / finance analytics server and its siblings) through one connector, authenticating with Kerberos/SPNEGO (negotiate) from your Windows logon - no key on disk for human users; service identities use a per-backend X-Punch-Auth key in backends.json. Auto-refreshes its tool catalogue when a backend changes (v3.3.0) and stamps which backend served each call (v3.4.0). Pairs with punch-analytics server v0.1.22+ (175 tools, including the R5 G/L open-item analytics).
